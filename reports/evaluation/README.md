# TraceGuard Evaluation Reports

This directory contains evaluation metrics and experimental benchmark reports generated by `ml/train_baseline.py`.

Generated artifacts:
- `baseline_binary_metrics.json`: Machine-readable evaluation results (confusion matrix, precision, recall, F1, PR-AUC, ROC-AUC, FPR, FNR, per-attack-family breakdowns).
- `baseline_binary_report.md`: Formatted report with performance tables, baseline comparisons, and leakage verification.
